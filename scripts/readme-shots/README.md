# README images: human-owned manual assets

This directory contains guidance only. README images are optional assets made,
reviewed and published manually by human maintainers. No capture code, image
tooling or CI image job belongs here.

Agents must not capture, open, inspect or render images. Automated native
evidence is text and structured state, as required by the no-vision policy in
[AGENTS.md](../../AGENTS.md). See [docs/SCREENSHOTS.md](../../docs/SCREENSHOTS.md)
for the human-only policy and historical evidence caveat.
